### Things I've Built

**01. ScanDocs** — Document Processing System

Built an Android OCR application for handling logistics documents at PT Indocement. Extracted data is stored in MySQL and accessible through a Laravel admin dashboard.

`Flutter` `Dart` `Laravel` `MySQL` `ML Kit`

**02. NutriLogic** — Personalized Diet Optimization

My undergraduate thesis project. A web-based system that generates personalized diet recommendations using greedy optimization with constraint satisfaction and Indonesian food composition data (TKPI).
